# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion on the work, and do not harass or
discriminate. Maintainers may remove comments, issues or contributions that violate this, and may
ban repeat offenders. Report problems through a private GitHub security advisory or by contacting the
maintainer via their GitHub profile.
